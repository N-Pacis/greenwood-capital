# BuildPath 🚀

**Rebuilding the financial infrastructure from an equity-first perspective.**

BuildPath is a community-powered microlending platform designed to dismantle the "Credit Paradox" faced by minority entrepreneurs. By replacing algorithmic bias with community validation and alternative data, we create accessible on-ramps to capital.

## 🌟 Key Features

- **Alternative Credit Scoring**: Uses rent payments, utility bills, and community reputation instead of just FICO scores.
- **Community Validation Circles**: Borrowers form groups to vouch for each other, replacing traditional collateral with social capital.
- **Investor Impact Portal**: Allows investors to filter by demographics (e.g., Woman-Owned, Veteran-Owned) and neighborhood to fight redlining.
- **Transparent Dashboards**: Full visibility into fees, score calculation, and capital flow.

## 🛠️ Tech Stack

- **Frontend Framework**: React 19 + Vite
- **Styling**: Vanilla CSS (Premium Dark Mode Design System)
- **Icons**: Lucide React
- **Routing**: React Router DOM

## 🚀 Getting Started

Follow these instructions to run the project locally.

### Prerequisites

- **Node.js**: You need to have Node.js installed on your computer. You can download it from [nodejs.org](https://nodejs.org/).
- **Git**: (Optional) To clone the repository.

### Installation

1. **Clone the repository** (or download the source code):
   ```bash
   git clone https://github.com/your-username/buildpath-hackathon.git
   cd buildpath-hackathon
   ```

2. **Install Dependencies**:
   This project relies on React and other libraries. Run this command to install them automatically:
   ```bash
   npm install
   ```

### Running the Application

1. **Start the Development Server**:
   ```bash
   npm run dev
   ```

2. **Open in Browser**:
   The terminal will show a local URL, typically:
   ```
   http://localhost:5173
   ```
   Click the link or copy-paste it into your browser to view the app.
